# BreathFlow

A simple PWA app to help you practice mindfulness breathing.

## Building PWA

```bash
npm install
npm run build
```

## Building for Android

```bash
npm install
npm run build
npx cap sync
npx cap open android
```

Then build and run the app from Android Studio.
